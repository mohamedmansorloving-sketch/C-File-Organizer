# Smart File Organizer

A fast Command Line Interface (CLI) tool built in C for local file management and organization. This project aims to practically apply Data Structures concepts (specifically N-ary Trees and search algorithms) to build a useful tool for daily tasks.

Key Features (Under Development):
- Lightning-fast file searching using Tree Traversal algorithms.
- Smart automated sorting (e.g., gathering scattered images and grouping photos of Alexandria, Aswan, and Marsa Matruh into dedicated albums).
- Isolating and organizing video files based on extensions or specific keywords in their names.
- Automated workspace cleanup by removing temporary files generated by the C compiler.
